# 🤖 AI IT Helpdesk Agent

An AI-powered IT Helpdesk Agent built using Node.js, Express and Ollama.

## Features

- AI-based IT troubleshooting
- Local AI model using Ollama
- Simple RAG knowledge retrieval
- Basic tool integration
- Interactive web chat interface
- No paid AI API required

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express
- Ollama
- Llama 3.2

## Project Architecture

User
↓
Web Interface
↓
Node.js / Express
↓
AI IT Helpdesk Agent
↓
RAG Knowledge + Tools
↓
Ollama
↓
AI Response
